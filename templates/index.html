Factores Clave del Modelo

  • Rendimiento del Lanzador Abridor: Análisis de FIP, WHIP y ponches por cada 9 entradas (K/9).
  • Estadísticas del Bullpen: Carga de trabajo reciente, tasa de efectividad de los cerradores y salvamentos blown.
  • Factor Parque (Park Factor): Ajuste ofensivo según las dimensiones del estadio y condiciones climáticas.

Configuración de Datos (Ejemplo de Automatización)


// Script de apoyo para cálculo de probabilidades logísticas
function calcularProbabilidad(eraPitcherA, eraPitcherB) {
    let base = 0.50;
    let ajuste = (eraPitcherB - eraPitcherA) * 0.07;
    return Math.min(Math.max(base + ajuste, 0.10), 0.90);
}
